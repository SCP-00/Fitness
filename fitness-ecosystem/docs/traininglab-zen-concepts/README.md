# Direcciones visuales para ZEN

Se usó la misma serie de remo, con 24 kg y 10 repeticiones, en los dos conceptos de GPT Image.

- [A · Registro compacto](A-compacto.png). La fila activa, la carga y la acción principal se localizan en la misma columna. Usar esta composición como referencia para PC.
- [B · Panel flotante](B-panel-flotante.png). El panel contextual da más aire a la técnica. Recuperar el encabezado plegable cuando falte espacio. El botón de cierre de sesión necesita una jerarquía secundaria.

Los números, iconos, imágenes de técnica y atajos de estas maquetas son datos de diseño. La implementación usará la prescripción real, los componentes de React, las demostraciones aprobadas y los comandos existentes. En móvil la entrada sigue precediendo a la técnica.
